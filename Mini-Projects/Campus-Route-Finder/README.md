# Campus Route Finder

A simple unweighted campus graph that finds a route between two locations using BFS.

## Data structures and algorithms
- Graph represented by an adjacency matrix
- Queue
- Visited and parent arrays
- Breadth-First Search (BFS)

## Compile and run
```bash
gcc -std=c11 -Wall -Wextra main.c -o route-finder
./route-finder
```
